# contracts/ - 跨仓契约目录

> Workspace 模式下，仓间 API / 事件 / 共享数据模型契约的**唯一真相源**。
> 单仓项目用不到本目录。

---

## 安装

无需单独安装：本目录随 `/sdd-starter:init` / `/sdd-starter:update` 一起复制到 workspace 的 `docs/contracts/`。

---

## 使用

1. **契约先行（MUST）**：任何仓间接口的新增/变更，先在本目录落契约文件，再改提供方与消费方代码
2. **各仓引用不复制**：仓级 SPEC 通过相对路径引用本目录条目，不把契约正文复制进仓
3. **一个契约一个文件**：按业务域命名，如 `order-api.md`、`user-events.md`
4. **既有契约平台不搬运**：若团队已用 Swagger/OpenAPI/proto 仓管理接口定义，本目录只放索引 + 语义补充（字段业务含义、错误码语义、兼容性承诺），链接到平台真相源
