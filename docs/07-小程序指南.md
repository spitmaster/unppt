# 小程序开发指南

> 微信小程序专项开发规范

---

## 小程序项目结构

```
project/
├── app.js                    # 应用入口
├── app.json                  # 应用配置
├── app.wxss                  # 全局样式
├── pages/                    # 页面目录
│   ├── index/
│   ├── detail/
│   └── mine/
├── components/              # 组件目录
├── utils/                   # 工具函数
├── services/                # API 服务
└── assets/                  # 静态资源
```

### 两种后端形态

| 形态 | 目录特征 | 请求方式 |
|------|---------|---------|
| **自建后端**（上图默认） | 根目录 `pages/` + `services/` | `wx.request` 调自有服务端 API |
| **微信云开发** | `miniprogram/`（前端）+ `cloudfunctions/`（云函数），由 `project.config.json` 的 `cloudfunctionRoot` 标识 | `wx.cloud.callFunction` 调云函数 |

两种形态都受本指南约束；目录与请求层的具体约定**以项目入口文档（CLAUDE.md / CODEBUDDY.md）声明为准**。脚手架自带的小程序 agent 组（miniprogram-orchestrator 等）同时适配两种形态，按项目声明的目录约定工作。

|------|------|----------|

### 3.1 首页功能
- Banner 轮播（高度、间隔、点击跳转）
- 分类导航（图标数量、布局）

## 4. 页面路由

```json
{
  "pages": [
    "pages/index/index",
    "pages/detail/detail",

  "tabBar": {
    "list": [
      { "pagePath": "pages/index/index", "text": "首页" },
      { "pagePath": "pages/mine/mine", "text": "我的" }
    ]
  }
}
```

## 5. 组件规范

```javascript
Component({
  properties: {
    title: { type: String, value: '' }
  },
  data: {},
  methods: {}

```

## 6. API 设计

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取首页数据 | GET | /api/home/index | Banner、分类 |

## DevTools 操作 Skill（miniprogram-dev-skill）

> 脚手架自带微信 DevTools 操作 skill，让 AI 能直接驱动微信开发者工具做预览、自动化验证和调试——agent 写完代码后，用它在真实环境里闭环验证。

### 能力范围

| Scene | 能做什么 |
|-------|---------|
| automator | 页面点击、输入、滚动、截图、断言页面状态 |
| debugger | 读 console / network、运行态诊断、清缓存 |
| compiler | 编译页面/文件、构建 npm、刷新模拟器 |
| previewer | 推送预览到手机（`auto_preview` 优先）、生成预览码、上传代码包 |
| cloudbase-operator | 云环境查询、云函数部署/日志、云数据库读写、云存储 |
| initializer / project-manager | 接管项目、登录检查、DevTools 项目列表管理 |

### 安装与位置

- `/sdd-starter:init` 选装 miniprogram agent 组时自动安装（Claude Code → `.claude/skills/miniprogram-dev-skill/`；CodeBuddy → 按需读取 `docs/skills/miniprogram-dev-skill/SKILL.md`）
- 入口与路由规则见包内根 `SKILL.md`；工具注册表见 `miniprogram-tools/references/tools.yaml`，**不要编造工具名**

### 前置依赖

1. 安装最新版微信开发者工具（较新版本自带 `wechatide` 命令行并注册系统 PATH）
2. DevTools 已扫码登录（游客态不可用）
3. 任何操作前先执行 `check_devtools_status`，确认返回含 `openid` 且无版本 `warning`
4. Windows 注意：`wechatide` 只在系统 PATH，Git Bash 里 `command not found` 时改用 PowerShell/CMD

### 典型用法

```text
> 把当前改动推预览到我手机上          → previewer / auto_preview
> 打开订单页截个图看看布局对不对        → automator（截图必须带 waitForSelector）
> 页面白屏了，看看 console 报什么错     → debugger
> 部署 joinPact 云函数并查一下日志      → cloudbase-operator
```
