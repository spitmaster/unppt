# 调研：没嵌入的思源字体该怎么显示（2026-10-24 ~ 26）

> 结论：**和没装思源的 PowerPoint 一样按缺字体替代**（用户 2026-10-26 定，SPEC D3 ⑩）。
> 本文只有汇总数字，不含任何单份课件的信息。

## 问题

5212 份真实课件里，**1857 份（36%）写了思源黑体 / 思源宋体 / Source Han / Noto CJK 等字体名**，但都没有把字体嵌入课件。
大多数电脑上没装这些字体（做参考图的这台也没装），PowerPoint 会按缺字体规则换成微软雅黑等。两种显示方法：

| 方法 | 所有观看者看到的一样？ | 和谁一致 |
|---|---|---|
| A 按同一套字形的开源字体（Noto Sans/Serif SC）显示，名字里的 Light / Bold 起作用 | 一样 | 装了思源的作者 |
| B 和 PowerPoint 一样按缺字体替代（雅黑的字宽、行高） | 一样 | 没装思源的电脑上的 PowerPoint |

0.3.0 用的是 A（10/22 假设"作者装了思源"）。全量比对发现用思源的课件因此大量偏离 PowerPoint 导出的参考图，于是用课件里自带的证据核对这个假设。

## 方法

两种互相独立的方法，都只在开发机上计算：

- **方法 A：存盘缩略图。** PowerPoint / WPS 存盘时会把第 1 页画成缩略图（`docProps/thumbnail.jpeg`），画的就是"最后保存的人"电脑上的样子。
  把缩略图分别和"按思源画"、"按雅黑画"的渲染比，看文字区域的粗细、面积更接近哪一个。用 88 份确定用雅黑的课件做对照组（把字体名改成
  思源再测），误判约 2%。
- **方法 B：不换行、自动调整大小的文本框宽度。** 这种文本框的宽度是作者那边的 PowerPoint 按文字实际宽度算出来存下的。
  分别用两种字体的字宽算一遍，看存下的宽度和哪种吻合。对照组宽度吻合 89.8%，行数吻合 98.9%；嵌入了思源的课件 14 份全部判为"装了"。

## 结果

| 口径 | 装了思源 : 没装 | 装了的占比 |
|---|---|---|
| A 缩略图，按课件（能判定的 178 份） | 66 : 112 | 37% |
| A 去掉同一模板的重复 | 45 : 51 | 47% |
| A 人工看图（115 个代表） | 42 : 52 | 45% |
| B 文本框宽度，按课件（能判定的 239 份） | 154 : 85 | 64% |
| B 每份至少 2 个文本框 | 35 : 44 | 44% |
| B 只看作者自己写的框（去掉模板里复制的） | 64 : 63 | 50% |
| B 按不同的文本框计数 | 123 : 175 | 41% |

- B 按课件算的 64% 主要是同一个模板框被复制到几十份课件里抬高的；去掉重复后两种方法都在 **41% ~ 50%**。
- 按保存软件分开看两种方法互相矛盾（例如 WPS：A 偏"没装"、B 偏"装了"），说明不能按保存软件定规则。
- 用思源的课件按 A 显示时，和 PowerPoint 导出的参考图逐页比：0.2.6（替代）平均 0.9527，A 平均 0.9461，**1.76 万页变差**。

## 决定

作者装没装思源大约一半一半，两种做法都会让约一半课件和"某个人看到的"不一样；但两种做法都保证所有观看者一致。
用户 2026-10-26 定："保证所有观看者的一致性是最最最重要的"——按 **B**，和大多数电脑上的 PowerPoint 一致，也和 0.2.6 一致。
想保留思源的样子，请把字体嵌入课件（PowerPoint：文件 → 选项 → 保存 → 将字体嵌入文件）。
