# 测试报告 0.3.2

> 这份报告由程序根据全量测试结果自动生成（2026-10-28）。只有汇总数字，不含任何一份课件的内容。

## 怎么测的

我们把每份课件用 unppt 转换，再把结果的每一页和 **Microsoft PowerPoint 自己导出的同一页图片**放在一起比较，得到一个**相似度**：0 到 1 之间，**1 表示两张图看起来一模一样**。（相似度用的是图像处理里常用的 SSIM 方法：比较明暗、对比和图形结构，比逐个像素对比更接近人眼的感受；具体算法和标准定义的链接见 [还原度：相似度是怎么算的](fidelity.md#ssim)。）

- **0.95 以上**：算"通过"，和 PowerPoint 的差别通常只是文字差一两个像素、图片边缘略有不同这类细节；
- **0.90 ~ 0.95**：整体一致，局部有能看出来的小差别；
- **0.90 以下**：有明显不同的地方，例如某个图表标签的位置、某种效果没画好。

## 测试环境（给想复现的开发者）

- 标准答案：Microsoft PowerPoint（PowerPoint.Application.16）导出的每页图片，宽 1280 像素
- 机器：AMD Ryzen 7 5800H with Radeon Graphics，16 个逻辑核，32 GB，Windows-11-10.0.26200-SP0，Node v26.4.0
- 真实课件比的是 unppt 的整页图（`pic/`，resvg 渲染）和参考图（缩到同样大小）的灰度 SSIM（8×8 分块）；用本机字体模式（`--system-fonts`），让字形和参考图一致、只看排版和绘制的差别。测试课件比的是浏览器里播放器的截图（[还原度](fidelity.md) 第 2 节）。
- 复现：`python tools/compare/sweep_ab.py run <目录> --cli new=packages/transcoder/dist/cli.js,--system-fonts`，再 `python tools/compare/corpus_report.py --results <目录>`。
