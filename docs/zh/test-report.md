## 测试环境和方法

- 参考答案：Microsoft PowerPoint（PowerPoint.Application.16）导出的每页图片，宽 1280 像素
- 机器：AMD Ryzen 7 5800H with Radeon Graphics，16 个逻辑核，32 GB，Windows-11-10.0.26200-SP0，Node v26.4.0
- 真实课件比的是 unppt 的整页图（`pic/`，resvg 渲染）和参考图（缩到同样大小）的灰度 SSIM（8×8 分块）；本机字体模式（`--system-fonts`），让字形和参考图一致、只看排版和绘制的差别。合成用例比的是浏览器里播放器的截图（[还原度](fidelity.md) 第 2 节）。
- 复现：`python tools/compare/sweep_ab.py run <目录> --cli new=packages/transcoder/dist/cli.js,--system-fonts`，再 `python tools/compare/corpus_report.py --results <目录>`。
