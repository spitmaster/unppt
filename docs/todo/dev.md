## 一、能用了吗

能。完整流程已经跑通：

```bash
npm install && npm run build
node packages/transcoder/dist/cli.js convert 你的文件.pptx -o out/index.html --system-fonts
```

**最快的看法**：运行 `.venv/Scripts/python tools/demo.py --samples`，然后双击打开 `.cache/demo/index.html`。左边是所有测试用例和你的样本，右边是播放器，下面的按钮就是通过跨 iframe 控制接口在操作播放器。

双击 `out/index.html` 就能播放：点击、方向键、空格、手机左右滑动都能翻页，动画能分步播放。嵌入和外部控制的用法见 [README](../../README.md)，可以直接打开 [examples/iframe-host.html](../../examples/iframe-host.html) 试跨域控制。

## 〇·三、继续补的功能（10/13 晚，按完成时间倒序）

- **艺术字效果**：文字发光、映像、内阴影（按 PowerPoint 截图校准，文字发光比形状发光紧凑）；
- **排版**：自定义制表位（左 / 居中 / 右 / 小数点对齐）、图片项目符号；
- **纹理填充**：平铺图片按图片自身的 DPI 和缩放算平铺尺寸（以前按固定大小铺，花纹偏大或偏小）；
- **PPTX 里嵌入的字体**：企业课件常把品牌字体嵌进文件。PowerPoint 存的是 MicroType Express 压缩格式，按 W3C 公开规范自己实现了解压（约 400 行，零依赖），解出来的字体和原字体逐点一致，8MB 的大字体不到 1 秒；转码时优先用它排版，并且总是做成子集放进产物，观看端没装也能正确显示；
- **艺术字文字变形**（波浪、膨胀、三角、拱形、圆形等 40 种全部支持）：读出字形轮廓，按 ECMA 标准里的变形定义弯曲成路径输出。规律都用 PowerPoint 实测校准（整段拉伸填满、多行怎么分配、拱形字的基线位置等，记在 SPEC 第 7 节），对比截图几乎一模一样。需要有字体文件（`--fonts` 或 `--system-fonts`），没有时按普通文字显示；
- **三维形状、三维文字正面提亮**：有棱台等三维效果的形状和艺术字，正面按 PowerPoint 的三点灯光提亮（实测公式 1.036×原值+5，10 种颜色完全吻合）；
- **Office 自带字体**：PowerPoint 能用 Office 私有字体和云字体（新版默认的 Aptos、主题里的 Gill Sans MT、Tw Cen MT 等），这些字体没装进系统；命令行现在会用上并嵌入产物。同时补上了跨文字段的字距调整。Office 主题、Integral 主题等页颜色误差减半；
- **渐变颜色和 PowerPoint 一致了**（之前记录为"规律前后不一致"的问题）：实测发现 PowerPoint 有两种画法——正好两个色标且在两端的渐变，在线性光空间混合并按 smoothstep 缓动；其它渐变是普通的 sRGB 线性插值。另外修正了径向渐变焦点矩形倒置时的中心位置，支持了随形状长宽比拉伸的渐变角度（scaled），径向渐变改成"终点是外接圆、起点是焦点"的实测几何，矩形渐变用四个梯形拼出（以前当成圆形）。全部合成用例的平均颜色误差下降 13%，Wisp 主题背景从 9.5 降到 1.2~2.1；渐变色线条也支持了；
- **表格斜线表头、竖排单元格**：单元格的左上-右下、左下-右上斜线（课表常用），单元格文字竖排 / 旋转 90 度；
- **复合线型**：双线、粗细线、三线边框按 PowerPoint 实测比例画（以前画成一条粗线）；
- **按计时自动放映**：PowerPoint 里设置了"自动换片时间"的课件会自动往下播（单击动画自动依次播放、等动画播完再翻页，规律用 PowerPoint 放映实测），"单击不换片"、"循环放映"也支持；嵌入时可用 `?timings=0` 关掉；
- **图表布局更精确**：坐标轴标签、图例的间距改成按 PowerPoint 实测的"随字号成比例"规律，标签宽度用真实字体量；4 种字号下绘图区都对齐到 1 像素以内，8 个图表页明显变好（新增的字号用例从 0.84 提到 0.94）；
- **动画重复和自动翻转**：课件里常见的"闪烁 3 次""一直转到下一次单击""放大后自动缩回"都按 PowerPoint 播放（以前只播一次、不翻回）；
- **逐字 / 逐词动画带位移**：以前逐字飞入、逐字缩放等一律按淡入播放；现在每个字拆成单独摆放的文字（位置取浏览器排好的结果，分毫不差），各自从幻灯片边缘飞入、缩放、擦除。顺带修正了组合里的对象做飞入、弹跳时的起点（按幻灯片坐标算）；
- **平滑切换（Morph）**：现代课件里很常用。前后两页里同名的对象从旧位置、旧大小平滑变到新位置、新大小，颜色变化表现为渐变，其余内容淡入淡出（以前当成普通淡入）。页面数据里每个对象多带了名字（`data-name`），除此之外所有测试用例的输出逐字节不变。

合成用例 206 页，通过 186（90%），平均相似度 0.981；原有页面只有 Gallery 主题第 1 页略降 0.008（标题字体换成了正确的 Gill Sans MT、位置完全对齐，剩下是嵌入字体的抗锯齿差别），其余没有变差。播放器端到端测试 Chrome、Firefox 全过；模糊测试（随机改坏 XML 300 轮、改坏嵌入字体 60 轮）0 崩溃。

## 四、需要你决定

1. **样本内容能否经过 AI 接口？** 我查看样本截图或文字时，内容会发给 AI 模型服务。所以今天我**没有看任何样本的图片和文字**，只看数字诊断（行数、位置、颜色均值、字体名、格式属性）。合成用例可以随便看。是否放开、放开到什么程度，由你决定。
2. **"通过"的标准**：现在用像素相似度 ≥ 0.95。文字多的页面即使排版完全正确，也会因为抗锯齿差异停在 0.90~0.95。建议改成以"换行一致 + 位置偏差"为主、像素相似度为辅。
3. **字体嵌入是否默认开启**：已经实现（`--embed-fonts`，只嵌入用到的字，每个字体通常十几 KB），开启后手机等没装字体的设备也能显示得和电脑上一样；不开启时观看端缺字体会用别的字体显示（换行位置固定，但字形和宽度会变）。现在默认关闭，因为微软雅黑等商业字体的分发授权需要你确认。
4. **比对报告加一个"颜色误差"指标**：像素相似度（SSIM）先转灰度再比结构，对颜色偏差几乎不敏感——这次渐变颜色修正让 Wisp 主题背景的平均颜色误差从 9.5 降到 1.2，但相似度一点没变。我是在评测工具之外临时算的颜色误差（RGB 平均绝对差）。建议把它加进 `tools/compare` 的报告作为辅助指标；按规则改评测工具要你同意，所以没动。
5. **导出工具等待时间**：`tools/powerpoint/export.py` 每个动画步骤只等"时长 + 延迟 + 0.6 秒"，没算重复播放和自动翻转，这类步骤会截早（这次用工具自带的 `UNPPT_WAIT_SCALE=3` 重新导出了相关用例）。建议让它把重复次数和翻转算进去；同样是评测工具改动，等你确认。
6. **iOS（WebKit）测试**：播放器端到端测试现在跑 Chrome 和 Firefox；要覆盖 iOS 的 WKWebView，需要运行 `playwright install webkit` 下载 Playwright 的 WebKit 浏览器（约 60MB）。下载需要你同意，所以没装。

## 七、样本怎么加

往 `samples/` 里随便放（可以按日期分文件夹），然后：

```bash
.venv/Scripts/python tools/powerpoint/export.py run   # PowerPoint 导出参考图（只处理新增的）
.venv/Scripts/python tools/compare/run.py --set all   # 比对，出报告
```

运行导出前请关掉自己打开的 PowerPoint（脚本会检查，避免动到你的文档）。
