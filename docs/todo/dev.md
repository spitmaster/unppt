```bash

node packages/transcoder/dist/cli.js convert 你的文件.pptx -o out/index.html --system-fonts
```

## 四、需要你决定

下面每条都给了推荐做法（**加粗**），你回一句"按推荐"或者逐条改就行。涉及评测工具、阈值、产物格式和字体授权，按规则我不能自己定，所以先起草在这里。

1. **评测的目标和通过标准**（M1 的完成标准、自动优化循环都依赖它）。现在"通过"只看像素相似度 ≥ 0.95，它对颜色几乎不敏感（渐变修正让 Wisp 主题背景颜色误差从 9.5 降到 1.2，相似度纹丝不动），文字多的页面排版全对也只有 0.90~0.95。
   **推荐：通过 = 换行全部一致 + 形状位置偏差 ≤ 2 像素 + 平均颜色误差 ≤ 3（RGB 0~255）；像素相似度降为辅助（低于 0.90 视为有明显问题）。把颜色误差加进 `tools/compare` 的报告。**
   daily 集：**样本不到 100 个时 daily 就是全部样本；之后按特征标签分层抽样（每个特征至少 3 个文件，总数不超过 100），名单固定存在 `.cache/`，样本库变化超过 20% 时重抽。**
   泛化检验：现在第 7 节的规律大多是用合成用例拟合、再用同类用例验收的。**推荐从样本里按哈希固定留出 20%（至少 3 个）作为留出集，不用来找规律，只在里程碑验收时跑；合成用例拟合出规律后，再换一组参数合成验证用例。**
2. **唯一的一套验收标准**（现在四份文档说法不一：SPEC 和 CLAUDE.md 写"testcases 全部通过"，但本来就有 20 页不通过；CONTRIBUTING 和 `/improve` 写"每页下降不超过 0.005"，没说超过了怎么办——Gallery 第 1 页降了 0.008 是我直接接受的）。
   **推荐写进 SPEC 5.4，其它文档只放链接：① 新用例的目标页面明显变好（相似度 +0.01 以上，或颜色误差 −1 以上，或从不通过变通过）；② 原来通过的页面不能变成不通过；③ 每页相似度下降不超过 0.005、颜色误差上升不超过 0.5；④ 超过的，只有在改动整体明显正确时（比如字体换成了正确的字体）才可以提交，并且要在提交信息和本文件里逐页写明，等你追认。** 统一后需要改 CLAUDE.md 和 `/improve` 的说明，等你同意再改。
3. **字体策略**（三条决策互相打架：D3 说"排版字体就是显示字体"，只有嵌入时才成立；第 8 节说嵌入默认关闭、等授权决定；F1 又规定 Office 私有字体、云字体和 pptx 自带字体总是嵌入）。
   **推荐：① pptx 自带的嵌入字体总是嵌入（作者已经把它放进了文件）；② 其它字体按字体文件里的嵌入许可（OS/2 fsType）决定：标了"受限、不允许嵌入"的一律不嵌入，其余在开关打开时嵌入；③ 开关默认关闭，Office 私有/云字体也遵守这个开关和许可标志（现在是总是嵌入，需要改）；④ D3 改成"换行位置在转码时用真实字体确定并写死在产物里；嵌入字体时显示和测量完全一致，不嵌入时字形和宽度可能有差别，但换行位置不变"。** 默认是否打开嵌入，取决于你对微软雅黑等商业字体分发授权的判断。
4. **平台目标**：D11 说要支持 iOS WKWebView，又说 Safari 不重点兼容——两者是同一个引擎（WebKit），而 WebKit 还没测过。**推荐：把 WebKit 列为必测目标，改 D11；同意我运行 `playwright install webkit`（下载约 60MB）。**
5. **音视频内不内联**：D10 写"一个自包含的 HTML"，D13 写"超过 2MB 的媒体外置"，按字面 2MB 以下的音视频应该内联，但实际一律放进 `media/`，结果只要有一段短音频，产物就不再是单个文件。**推荐：小媒体和图片一样，低于内联阈值（默认 2MB）的音频、视频也内联，超过的外置；同时改 D10、D13 的措辞写清楚。**
6. **播放端体积目标**：D13 解决了转码时的内存，但几百页、图片很多的课件，单个 HTML 可能大到手机打不开。**推荐：单个 HTML 目标不超过 50MB；内联的图片和媒体累计超过 30MB 后，后面的改为外置（新增 `--inline-total` 参数）；更大的课件建议用 `--data` 方式由服务端托管。**
7. **产物格式的兼容规则**：D4 说两部分只靠格式耦合、可以各自升级，但格式加了很多字段，版本号一直是 1。**推荐写进 SPEC 和格式文件开头：只加"旧播放器忽略也能正常播放"的可选字段时版本号不变（例如新的切换类型旧播放器按淡入、`behaviors` 旧播放器按效果名）；改变已有字段的含义、新增必须理解的字段时版本号加 1；播放器遇到比自己新的版本号明确报错。** 改格式要你同意，所以只起草。
8. **"不改参考结果"的细化**：这条没区分"修导出工具的缺陷"和"为了刷分改答案"（anim-repeat 的参考图因为导出工具截早重新导出过两次）。**推荐：新用例可以自己导出参考图；修改已有用例的参考图时，提交信息里写明原因（例如导出工具的什么缺陷），并在本文件列出，由你追认。** 导出工具等待时间没算重复播放和自动翻转（会截早），对 SmartArt"逐个"这类只动一部分的动画也按整体模拟（分步参考图不对），静态导出也不画视频的封面帧（放映时 PowerPoint 显示首帧，参考图却是空白），**推荐顺便改掉（这类动画和视频改用放映截图）**，同样等你同意。另外 anim-after 第 1 页的 4 张参考图是窗口放映直接截的，带了上下黑边和右侧滚动条（分数被压到 0.94~0.97，内容本身是对的），**推荐重新截一次并裁掉窗口边框**。
9. **样本内容能否经过 AI 接口**：我查看样本截图或文字时，内容会发给 AI 模型服务，所以一直**没有看任何样本的图片和文字**，只看数字诊断。是否放开、放开到什么程度，由你决定（推荐保持现状）。
10. **流程文档**：CONTRIBUTING 写"一个需求一个分支"，实际现在全部直接提交在 dev 上。**推荐：在 CONTRIBUTING 里写明"0.0.1 阶段（你 + agent）直接在 dev 上提交；有其他贡献者后改为一个需求一个分支"。** `docs/` 下约 70 个 sdd-starter 通用模板（小程序、3D、agents 等）和本项目无关，**推荐移到 `docs/sdd-starter/` 下**；先在 `docs/README.md` 开头说明了哪些是本项目文档。

## 变更日志（按时间倒序）

### 10/13 晚 ~ 10/14：继续补的功能（按完成时间倒序）

- **图表区、绘图区的背景**：绘图区的填充和边框以前不画（Excel 2003 风格的灰色绘图区在老课件里常见），图表区只支持纯色；现在纯色、渐变和边框都画。新增用例 charts-fills（0.909 → 0.957，散点图页 0.975 → 0.978）；
- **坐标轴标题**：物理、数学课件里图表常带"时间 (s)""速度 (m/s)"这样的坐标轴标题，以前完全不画。现在按 COM 实测的规律画（标题框厚度、离图表边的距离、绘图区让出的空间），柱形、折线、条形、散点、气泡图都支持。新增用例 charts-axis-titles（0.944/0.940）；
- **图表数据表、折线空值、垂直线和涨跌柱**：图表下方的数据表以前不画，现在按实测规律画（行高、左列宽度、表格线，误差 ≤ 1 像素）；折线图的空值按文件里的设置留空/按零/连线（以前一律连线）；折线图的垂直线、高低点连线、涨跌柱以前只在股价图里画。新增用例 charts-extras（3 页：0.741/0.945/0.943 → 0.875/0.968/0.969）；
- **三维形状在各种灯光、材质下的正面颜色**：以前只有默认三点灯光的规律。实测了 PowerPoint 全部 27 种灯光方案 × 15 种材质（老式灯光暗得多、线框/透明材质接近白、晨光日落等带色调），做成查表；SmartArt 三维样式用的正是这些非默认灯光。smartart-3d 颜色误差 13~17 降到 5~7；顺带发现只开了三维旋转、没有棱台的形状和图片 PowerPoint 也会提亮正面（以前没提亮），shapes-3d-rotation 颜色误差 6.5/1.7 → 4.5/1.4；
- **三维旋转的真透视**：透视类相机预设（图片样式里的"透视阴影""棱台透视"、SmartArt 三维样式）以前用仿射近似，远近两边一样长；现在形状轮廓逐点投影（近大远小、没有接缝、文件不变大），图片按网格三角形透视，文字仍是仿射近似。shapes-3d-rotation 0.957/0.964 → 0.975/0.978，smartart-3d 第 2、3 页 0.821/0.792 → 0.873/0.829；
- **渐变文字按行铺**：用硬边渐变量出 PowerPoint 的规律——每一行各自铺一遍渐变，范围是这一行文字的宽度 × 行高，和文本框多高无关；以前按整个文本框铺，文本框比文字高时颜色整体偏向起始色。text-effects 渐变文字逐行颜色误差从 30~70 降到 5 以内（相似度对颜色不敏感，分数没变）；
- **JPEG 的"设置透明色"**：老师常对 JPEG 剪贴画去白底。实测 PowerPoint 对 JPEG 的阈值是每个通道差 ≤ 16（PNG 只有 ≤ 1），并且在原图上抠；以前我们用滤镜在缩小后抠，留一圈亮边。现在自己写了 JPEG 解码器（基线、渐进式、各种采样、重启标记、灰度和 CMYK，和 Pillow 的解码结果平均差 0.05），在原图上抠完存成 PNG。picture-transparent 0.943 → 0.980。抠完的 PNG 比原 JPEG 大 3~4 倍（以后可以改成原 JPEG + 灰度遮罩）；

- **逐字 / 逐词动画带位移**：以前逐字飞入、逐字缩放等一律按淡入播放；现在每个字拆成单独摆放的文字（位置取浏览器排好的结果，分毫不差），各自从幻灯片边缘飞入、缩放、擦除。顺带修正了组合里的对象做飞入、弹跳时的起点（按幻灯片坐标算）；
- **平滑切换（Morph）**：现代课件里很常用。前后两页里同名的对象从旧位置、旧大小平滑变到新位置、新大小，颜色变化表现为渐变，其余内容淡入淡出（以前当成普通淡入）。页面数据里每个对象多带了名字（`data-name`），除此之外所有测试用例的输出逐字节不变。
