## 五、还没做的

- **出图速度（必须优化，你 10/15 明确不能接受现在的速度）**：开着整页图和缩略图时，35 页的课件 16.7 秒、74 页的 17.8 秒（不出图都是 0.8 秒），峰值内存 350~550 MB。剖析（35 页）：resvg 渲染约 11 秒（WASM 单线程；每页都要把用到的字体文件整个交给它重新解析），纯 JS 的 JPEG 编码约 3 秒（DCT 和熵编码）。可选方向：同一份字体只解析一次、多核并行（Worker）、更快的 DCT（AAN 算法）、出图和转码拆成两步、按需出图；
- 图表：透视投影（非直角坐标轴）的三维柱形图、透视三维图转角 > 60° 或负俯角时坐标轴换边、曲面图（瀑布图、漏斗图等新图表 PowerPoint 存了后备图片，能显示）；趋势线的图例键长度、分类轴在中间（有负数）时标签的位置、饼图窄扇区挨着标题时外侧标签的避让还没对齐；布局还可以更精确

### 10/15 夜：用第一批真实课件（200 多份）验证和优化

每一项都先用 PowerPoint 生成中性探针或测试用例量出规则（写进 SPEC 第 7 节），再改代码；合成用例全部无回退。
样本整体（只记总分）：第二轮 通过 63.7% / 平均 0.950 → 第三轮 64.7% / 0.952 → 第四轮 66.2% / 0.955 → 第五轮 72.3% / 0.961 → 第六轮 73.7% / 0.962 → 第七轮 73.8% / 0.963 → 第九轮 76.4% / 0.965 → 第十一轮 76.5% / 0.965（第八、十轮中途比对工具页面加载 / 截图超时崩溃，作废，比对工具已改成超时重试一次、仍失败跳过这一页）。

- **排版单位 1/8 磅**：PowerPoint 每个字的宽度四舍五入到 1/8 磅，摆位置和断行都用取整后的宽度；整行宽度向上取整后不超过可用宽度才放得下（字间距让行宽正好等于框宽时也要换行）。以前长西文行行尾差 1~2 磅。用例 text-layout-unit；
- **缺失字体按字符集选替代字体**：标日文字符集的缺失字体（思源黑体类常见）PowerPoint 用 Yu Gothic，它没有的简体字用雅黑补——以前一律雅黑，字明显偏粗、断行不同。同一个字体名共用一个字符集，PowerPoint 按页加载：渲染第 k 页时用到这页为止最后一次写的（后面页面写的不影响前面）。用例 text-missing-font-jp、text-charset-slides；
- **文本框和形状只用演示文稿默认样式**（母版 otherStyle 只给表格用），形状样式和表格样式的 fontRef 主题字体生效。用例 text-default-style、text-latin-cjk-font；
- **按中文习惯控制首尾字符（eaLnBrk）关掉时不做行首行尾禁则**（老模板的默认样式常见）。用例 text-ea-line-break；
- **中文里的引号按全角**：文字语言是中日韩时引号用东亚字体、占一个字宽；破折号后面可以断行。用例 text-ambiguous-punct；
- **文字块高度**：多倍行距的最后一行只算到基线加下伸（居中、底端对齐和撑高表格行都用它；段落字体对齐 ctr、t 时除外）。用例 text-anchor-linespacing、table-linespacing、table-fontalgn；
- **图片的形状沿占位符继承链找**：版式占位符是自定义形状时按它裁剪，哪里都没有形状就不画（以前一律按矩形画）。用例 placeholders-picture-geom；
- **EMF 渐变填充**（118 号记录）。用例 emf-gradient-fill；
- **主题东亚字体为空时按文字语言选主题脚本字体**（zh-CN 等线、ja-JP 游ゴシック、zh-TW 新細明體、ko-KR 맑은 고딕）；英文或没写语言时东亚字体就用西文字体（楷体、宋体、Yu Gothic 等用自己的中文字形和行高，Arial 这类没有中文字形的用雅黑补）。第一版只用 Arial 测、规则写成"一律雅黑"，第九轮里西文字体写宋体的课件因此退步，已按 16 种西文字体的探针改正。用例 text-theme-font-lang、text-theme-font-latin；
- **段落右缩进（marR）**：以前完全没实现，换行和对齐都没扣右缩进。PowerPoint 界面里没有这个设置，PDF 转换来的课件常见（文本框右侧留很宽的空白）。用例 text-margin-right；
- **自动缩小后的字号四舍五入到整数磅**（行距也按取整后的字号算）。用例 text-autofit-round；

- **图表常用选项**：以前忽略的一批设置现在按 PowerPoint 画：平滑线、逆序类别 / 逆序刻度值（条形图常用，数值轴会跑到上面）、坐标轴交叉位置、饼图扇区分离、次要网格线、刻度线、对数刻度、显示单位（"千"等）、趋势线（线性、指数、对数、多项式、乘幂、移动平均，图例里单独一项）、误差线（固定值、百分比、标准偏差、标准误差、自定义）。顺带修正了折线图例：线和系列一样粗、有线条项时所有图例键等宽（逐像素对照参考图）。规律记在 SPEC 第 7 节。新增用例 charts-options（4 页 0.94~0.97，原来 0.87）；其它图表页持平或略好。代码上把图例、分类轴图的坐标轴从 chart.ts 拆了出来（先单独做了一次输出逐字节不变的重构）；
- **音视频控制条**：和 PowerPoint 放映一样，鼠标移到视频（或音频图标）上，下方出现控制条：播放/暂停、拖动进度、时间；触屏点一下出现。顺带修了点视频不能播放的问题（以前视频上的点击被当成"不处理"直接丢掉）。在控制条上点击、在进度条上按方向键都不会翻页。新增用例 media-video（测试视频用 ffmpeg 生成的彩条图案）。**注意**：PowerPoint 静态导出不画视频封面（参考图里视频位置是空白），放映截图确认放映时显示的是首帧、和我们一致，所以只保留了画出视频的那一张参考图，其余由端到端测试检查（见「四」第 8 条）。另外，外部媒体文件要由支持 Range 请求的服务器提供才能在 Chromium 里拖进度（常见 Web 服务器都支持；测试用的本地服务器补上了）；
- **气泡图**（含三维气泡）：以前是"不支持的图表类型"。气泡大小、坐标轴为气泡留的空间都按 PowerPoint 实测拟合（记在 SPEC 第 7 节）；散点图和气泡图的坐标框架抽成公共模块。新增用例 charts-bubble（3 页 0.94~0.95，差别主要是 PowerPoint 平面气泡图的网格线画得更深）；
- **文字强调效果**：突出关键词常用的更改字体颜色、加粗、倾斜、下划线、加粗闪烁、样式强调、更改字号。按 PowerPoint 的规则区分"一直保留"和"只在效果过程中出现"（例如设了时长的"更改字形"到时间就恢复，是放映实测确认的）；更改字号按左上角放大近似（PowerPoint 会重新排版）。新增用例 anim-text-emphasis（7 个分步全部是放映截图参考，0.978~0.993）；
- **"动画播放后"选项**：讲解要点时常用的"播放后变暗"（上一条要点变灰）、"播放后隐藏"、"下次单击后隐藏"以前不生效；现在按 PowerPoint 的时机执行（规律用放映逐步截图确认，记在 SPEC 第 7 节）。新增用例 anim-after；第 2 页的形状隐藏导出工具模拟不了，只保留第 0 步参考图，过程由端到端测试检查。测试浏览器改成静音（动画声音的测试会出声）；
- **SmartArt "逐个"动画**：培训课件里很常见（流程、要点一个一个出来）。以前整个 SmartArt 第一下就全部出现，后面的点击没反应；现在每个形状单独按点击出现。动画目标指向哪个 id，是手写时间线让 PowerPoint 放映逐步截图确认的（记在 SPEC 第 7 节）。COM 做不出这种动画，用例 anim-build 是保存后补的时间线。**注意**：导出工具对这类动画按"整个 SmartArt"模拟分步，截出的第 1~4 步参考图是错的（和 PowerPoint 放映不符），所以只保留了第 0 步和最后一步的参考图，过程由端到端测试检查；修导出工具要你同意（见「四」第 8 条）。图表的"按系列/按类别"动画也支持了：先出现坐标轴、网格和图例，再逐个系列或逐个分类出现（写法同样用 PowerPoint 放映逐步截图确认），用例 anim-build 的第 2、3 页；
- **动画音效、切换声音**：课件里常见的"鼓掌""照相机""风铃"等声音以前不响。现在动画附带的声音在动作开始时播放，切换声音在翻页时播放（支持"循环到下一个声音""停止前一声音"），同一时间只有一个声音，和 PowerPoint 一样翻页不停；跳转、深链接打开时不出声。顺带修了只有声音没有切换效果的页会被当成淡入切换的问题。新增合成用例 anim-sound（声音是自己生成的提示音）；
- **进入/退出动画改成按 PowerPoint 的"行为"播放**：PowerPoint 文件里每个动画其实写着具体行为（位置、大小、旋转、透明度的关键帧和公式，加减速、时间折线，显现滤镜）。以前按"预设编号"套固定画法，速度曲线和细节都是估的；现在转码器把行为原样带过来，播放器按元素的真实位置代入公式、按时间变换采样播放，上百种预设和自定义动画都自然覆盖。用放映逐帧截图对照了 38 种进入/退出效果：飞入（原来误差 0.077）、弹跳（0.099）、中心旋转（0.157）、折叠（0.101）、移入、翻转、退出擦除方向、退出形状等全部降到 0.03 以内。量出来的规律（飞入是匀速的、退出不是倒放而是"被隐去的部分按同一滤镜长大"、圆形其实是椭圆等）记在 SPEC 第 7 节。强调动画和路径动画也按行为的加减速、时间折线播放（陀螺旋 0.079 -> 0.027、透明 0.052 -> 0.010、闪光灯 0.089 -> 0.012）；
- **页面切换按 PowerPoint 放映逐帧校准，从 9 种增加到 22 种**：新写了对照工具（`tools/powerpoint/transitions.py`），让 PowerPoint 真正放映、每秒约 60 帧带时间戳截图，再把我们的播放器停在同一时刻比较。量出来的规律（记在 SPEC 第 7 节）：淡入是余弦速度曲线；擦除、分割、条纹、圆形、菱形、加号、轮子、扇形都是"一条软边匀速扫过"（以前画成硬边）；盒状只用一半时间；覆盖、揭开、推入各有自己的速度曲线。新增穿过黑色淡出/切出、闪光、条纹、菱形、加号、盒状、轮子（1~8 条轮辐、逆时针）、扇形、新闻快报、百叶窗、棋盘、梳理、随机线条、溶解，覆盖/揭开支持斜向；浏览器画不了的 3D 切换（立方体、翻转、窗帘、折纸等）逐个比较了几种平面近似，选误差最小的。软边类和 PowerPoint 的逐像素平均误差 0.01~0.05，Chrome、Firefox 一致；
- **艺术字效果**：文字发光、映像、内阴影（按 PowerPoint 截图校准，文字发光比形状发光紧凑）；
- **排版**：自定义制表位（左 / 居中 / 右 / 小数点对齐）、图片项目符号；
- **纹理填充**：平铺图片按图片自身的 DPI 和缩放算平铺尺寸（以前按固定大小铺，花纹偏大或偏小）；
- **PPTX 里嵌入的字体**：企业课件常把品牌字体嵌进文件。PowerPoint 存的是 MicroType Express 压缩格式，按 W3C 公开规范自己实现了解压（约 400 行，零依赖），解出来的字体和原字体逐点一致，8MB 的大字体不到 1 秒；转码时优先用它排版，并且总是做成子集放进产物，观看端没装也能正确显示；
- **艺术字文字变形**（波浪、膨胀、三角、拱形、圆形等 40 种全部支持）：读出字形轮廓，按 ECMA 标准里的变形定义弯曲成路径输出。规律都用 PowerPoint 实测校准（整段拉伸填满、多行怎么分配、拱形字的基线位置等，记在 SPEC 第 7 节），对比截图几乎一模一样。需要有字体文件（`--fonts` 或 `--system-fonts`），没有时按普通文字显示；
- **三维形状、三维文字正面提亮**：有棱台等三维效果的形状和艺术字，正面按 PowerPoint 的三点灯光提亮（实测公式 1.036×原值+5，10 种颜色完全吻合）；
- **Office 自带字体**：PowerPoint 能用 Office 私有字体和云字体（新版默认的 Aptos、主题里的 Gill Sans MT、Tw Cen MT 等），这些字体没装进系统；命令行现在会用上并嵌入产物。同时补上了跨文字段的字距调整。Office 主题、Integral 主题等页颜色误差减半；
- **渐变颜色和 PowerPoint 一致了**（之前记录为"规律前后不一致"的问题）：实测发现 PowerPoint 有两种画法——正好两个色标且在两端的渐变，在线性光空间混合并按 smoothstep 缓动；其它渐变是普通的 sRGB 线性插值。另外修正了径向渐变焦点矩形倒置时的中心位置，支持了随形状长宽比拉伸的渐变角度（scaled），径向渐变改成"终点是外接圆、起点是焦点"的实测几何，矩形渐变用四个梯形拼出（以前当成圆形）。全部合成用例的平均颜色误差下降 13%，Wisp 主题背景从 9.5 降到 1.2~2.1；渐变色线条也支持了；
- **表格斜线表头、竖排单元格**：单元格的左上-右下、左下-右上斜线（课表常用），单元格文字竖排 / 旋转 90 度；
- **复合线型**：双线、粗细线、三线边框按 PowerPoint 实测比例画（以前画成一条粗线）；
- **按计时自动放映**：PowerPoint 里设置了"自动换片时间"的课件会自动往下播（单击动画自动依次播放、等动画播完再翻页，规律用 PowerPoint 放映实测），"单击不换片"、"循环放映"也支持；嵌入时可用 `?timings=0` 关掉；
- **图表布局更精确**：坐标轴标签、图例的间距改成按 PowerPoint 实测的"随字号成比例"规律，标签宽度用真实字体量；4 种字号下绘图区都对齐到 1 像素以内，8 个图表页明显变好（新增的字号用例从 0.84 提到 0.94）；
- **动画重复和自动翻转**：课件里常见的"闪烁 3 次""一直转到下一次单击""放大后自动缩回"都按 PowerPoint 播放（以前只播一次、不翻回）；
- **逐字 / 逐词动画带位移**：以前逐字飞入、逐字缩放等一律按淡入播放；现在每个字拆成单独摆放的文字（位置取浏览器排好的结果，分毫不差），各自从幻灯片边缘飞入、缩放、擦除。顺带修正了组合里的对象做飞入、弹跳时的起点（按幻灯片坐标算）；
- **平滑切换（Morph）**：现代课件里很常用。前后两页里同名的对象从旧位置、旧大小平滑变到新位置、新大小，颜色变化表现为渐变，其余内容淡入淡出（以前当成普通淡入）。页面数据里每个对象多带了名字（`data-name`），除此之外所有测试用例的输出逐字节不变。

合成用例 238 页（新增切换用例 32 页），通过 218（92%），平均相似度 0.984；此前：206 页，通过 186（90%），平均相似度 0.981；原有页面只有 Gallery 主题第 1 页略降 0.008（标题字体换成了正确的 Gill Sans MT、位置完全对齐，剩下是嵌入字体的抗锯齿差别），其余没有变差。播放器端到端测试 Chrome、Firefox 全过；模糊测试（随机改坏 XML 300 轮、改坏嵌入字体 60 轮）0 崩溃。
