把 PowerPoint 转成网页，
看起来和 PowerPoint 一模一样

Turn PowerPoint into a web page
that looks exactly like PowerPoint

unppt 把 .pptx 转成静态产物（SVG + JSON + 资源），由一个可以嵌进任何网页、可以被外部控制的播放器播放：形状、图表、SmartArt、表格、动画、切换、音视频都在。字体打包进产物，Windows、Mac、手机上所有观看者看到的完全一样。开源，Apache-2.0。

unppt converts .pptx into static output (SVG + JSON + assets) played by an embeddable, scriptable web player — shapes, charts, SmartArt, tables, animations, transitions, audio and video. Fonts are embedded, so every viewer on Windows, Mac or phones sees exactly the same. Open source, Apache-2.0.

安装和使用Install and use

npm install -g @unppt/unppt
unppt 课件.pptxslides.pptx      # 输出到旁边的同名文件夹，打开里面的 index.html# writes a folder next to it; open its index.html

需要 Node.js 20.12 以上。也可以在代码里调用 convert()：字节进、文件出，不读写磁盘、不联网，可以直接放进云函数。

Requires Node.js 20.12+. Or call convert() from code: bytes in, files out, no disk or network access — ready for cloud functions.

用 5000 多份真实课件逐页比对Checked slide by slide on 5,000+ real decks

每一页都和 PowerPoint 自己导出的同一页图片比较，算出相似度（0 到 1，1 表示看起来一模一样；用的是图像比较的通用方法 SSIM）。完整的分项统计见 Every slide is compared with the image PowerPoint itself exports, giving a similarity score (0 to 1, 1 = looks identical; the standard SSIM method). Full breakdown in the 测试报告test report.

特点Features

效果对齐 PowerPoint

Matches PowerPoint

换行、行距、图表坐标轴、项目符号……都按 PowerPoint 实测的规则排，排版和原文件一致。

Line breaks, spacing, chart axes, bullets… follow rules measured in PowerPoint, so the layout matches.

所有观看者一致

Same for every viewer

不用观看者电脑上的字体：用到的字做成字体子集打包进产物，直播课里几千个学生看到的完全一样。

Never uses viewers' fonts: glyphs are subset and embedded, so thousands of viewers see identical slides.

动画、切换、音视频

Animations, transitions, media

进入、强调、退出、路径动画，触发器，自动换片，页面切换效果，音视频。

Entrance, emphasis, exit and motion-path animations, triggers, auto-advance, slide transitions, audio and video.

可嵌入、可控制

Embeddable and scriptable

iframe 跨域嵌入，用 postMessage 控制翻页、接收事件；直播课演绎端 / 观看端同步。

Embed via iframe across origins, drive it with postMessage and receive events; presenter / viewer sync for live classes.

转码器是纯函数

Pure-function transcoder

不依赖 Office、LibreOffice 或任何外部程序，不需要原生插件，可以直接放进云函数；1GB 级文件也能小内存转码。

No Office, LibreOffice or other external programs, no native add-ons — runs in cloud functions; handles 1 GB files with little memory.

播放器零依赖

Zero-dependency player

约 58KB（gzip 后约 21KB），按需加载：入口只有几十 KB，看到哪页才加载哪页。

About 58 KB (21 KB gzipped), loads on demand: the entry is tens of KB, each slide loads when shown.
